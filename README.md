# 시네픽 (Cinepick)

## 실행
`index.html`을 브라우저에서 열거나 GitHub Pages로 배포해 확인할 수 있습니다.

## 폴더 구조
- `index.html`: 메인 페이지
- `pages/`: 추가 HTML 페이지용 폴더
- `css/style.css`: 스타일
- `js/app.js`: 화면 동작 및 영화 추천 기능
- `data/`: 데이터 파일을 둘 폴더
- `asset/`: 이미지 및 아이콘 폴더

현재 전달받은 원본은 단일 페이지 앱이므로 별도 화면은 `index.html` 내부에서 전환됩니다. 영화 데이터도 현재 `js/app.js` 안에 포함되어 있습니다.
