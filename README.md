# 시네픽 JSON 데이터 정리 과제

## 폴더 구성
- `1018.html`: 현재 시네픽 프로토타입 원본(수정하지 않음)
- `data/movies.json`: 영화 데이터 샘플 10개
- `data-spec.md`: 필드 정의와 데이터 작성 규칙

## 이번 단계에서 할 일
1. VS Code에서 `data/movies.json`을 열어 JSON 문법을 확인합니다.
2. `data-spec.md`의 필드와 규칙이 실제 JSON 데이터와 일치하는지 확인합니다.
3. 이 폴더를 기존 GitHub 프로젝트에 추가하고 커밋합니다.

## 이번 단계에서 하지 않는 일
JSON을 HTML에 연결하는 `fetch`, 영화 카드 렌더링, 검색·필터·정렬 기능은 아직 구현하지 않습니다. 기존 HTML의 영화 배열도 이 단계에서는 삭제하거나 교체하지 않습니다.
