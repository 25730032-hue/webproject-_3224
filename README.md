# Cinepick (시네픽)

> **현재 버전: PRD 0.4**  
> 영화 선택부터 감상 기록까지 이어지는 모바일 중심 영화 큐레이션 웹앱입니다.

## 1. 프로젝트 개요

시네픽은 사용자의 기분과 취향에 맞춰 영화를 추천하고, 영화를 선택한 뒤 티켓과 감상평을 기록할 수 있도록 돕는 웹앱입니다.

### 핵심 목표
- 사용자가 복잡하게 검색하지 않고도 볼 영화를 고를 수 있도록 돕습니다.
- 기분 기반 추천과 영화 탐색을 함께 제공합니다.
- 찜한 영화, 티켓북, 리뷰를 통해 개인의 영화 감상 기록을 관리합니다.

## 2. 주요 기능

| 구분 | 기능 | 설명 |
|---|---|---|
| 홈 | 오늘의 영화 및 바로가기 | 홈 화면에서 영화 검색과 주요 기능으로 이동 |
| 영화 추천 | 기분 기반 추천 | 기분을 선택해 영화 후보를 확인 |
| 영화 추천 | 룰렛 및 결정 타이머 | 후보 중 영화를 선택하고 결정할 수 있도록 지원 |
| 영화 기록 | 티켓 발권 및 티켓북 | 선택한 영화를 티켓으로 기록하고 모아보기 |
| 탐색 | 영화 목록 및 검색 | 영화 제목, 배우, 장르 등을 기준으로 탐색 |
| 탐색 | 필터 | 장르, 개봉 연도, 러닝타임 기준으로 필터링 |
| 영화 상세 | 상세 정보 | 포스터, 개봉 연도, 장르, 러닝타임, 줄거리 확인 |
| 찜 | 찜한 영화 | 관심 영화를 저장하고 마이페이지에서 확인 |
| 리뷰 | 리뷰 작성 및 조회 | 영화별 감상평과 별점을 작성하고 확인 |
| 마이페이지 | 개인 기록 | 티켓북, 찜한 영화, 시네마 기록 확인 |

## 3. 기술 및 데이터 관리

- **Frontend:** HTML, CSS, JavaScript
- **영화 데이터:** `data/movies.js`에 포함된 로컬 영화 데이터 150편
- **외부 API:** TMDB API를 통한 영화 목록, 검색 및 포스터 정보 연동
- **브라우저 저장:** 찜, 리뷰, 티켓 등 사용자 기록은 브라우저의 `localStorage`를 사용합니다.

> 참고: 사용자 기록은 현재 브라우저에 저장됩니다. 다른 기기나 브라우저와 자동 동기화되지는 않습니다. TMDB API 사용을 위해서는 프로젝트 코드에 설정된 API 키가 유효해야 합니다.

## 4. 폴더 구조

```text
cinepick/
├── index.html                 # 메인 진입 HTML (PRD 0.4)
├── README.md                  # 프로젝트 설명 및 변경 이력
├── asset/
│   └── README.md              # 정적 리소스 폴더 안내
├── css/
│   └── style.css              # 전체 화면 및 반응형 스타일
├── data/
│   └── movies.js              # 로컬 영화 데이터 150편
├── js/
│   └── app.js                 # 화면 렌더링 및 주요 기능
└── pages/
    ├── browse.html
    ├── help.html
    ├── movies.html
    ├── mypage.html
    ├── recommend.html
    └── ...                    # 작업 과정에서 보관한 페이지 및 시안
```

## 5. 실행 방법

1. 저장소를 내려받거나 GitHub에서 프로젝트를 클론합니다.
2. 프로젝트 최상위 폴더에서 `index.html`을 엽니다.
3. 로컬 서버 또는 GitHub Pages에 배포해 실행할 수 있습니다.

`index.html`은 `data/movies.js`를 먼저 불러온 뒤 `js/app.js`를 실행하도록 구성되어 있습니다. CSS는 `css/style.css`에서 불러옵니다.

버전은 `PRD major.minor` 형식으로 관리합니다. 기능 또는 화면 구조가 변경되면 아래 표에 버전, 변경 내용, 비고를 추가합니다.

| 버전 | 기록일 | 변경 내용 | 비고 |
|---|---|---|---|
| **PRD 0.4** | 2026-11-16 | 현재 프로젝트 기준 버전 정리. 메인 HTML과 CSS·JavaScript·데이터 파일 분리 구조 반영. 홈/탐색/리뷰/마이 탭, 기분 기반 영화 추천, 룰렛, 티켓북, 영화 검색·필터, 상세 정보, 찜 및 리뷰 기능을 포함. README에 프로젝트 개요와 버전 관리 기준 추가. | 현재 기준 버전 |

### 변경 이력 작성 규칙

새로운 변경 사항을 반영할 때 다음 기준으로 이력을 추가합니다.

- **기능 추가:** 새 기능과 사용자가 할 수 있게 된 일을 기록합니다.
- **기능 수정:** 변경한 동작과 화면을 구체적으로 기록합니다.
- **오류 수정:** 발생한 문제와 해결 내용을 기록합니다.
- **구조 변경:** 파일 이동, 폴더 분리, 데이터 구조 변경 등을 기록합니다.

변경 이력은 최신 버전이 위에 오도록 관리합니다.

- 영화 데이터와 포스터 등 일부 정보는 TMDB API를 통해 제공됩니다.

- 배포 시에는 `index.html`, `asset/`, `css/`, `data/`, `js/` 경로가 유지되어야 합니다.
